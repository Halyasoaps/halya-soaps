# HALYA soaps — Free Starter Website

## Preview
Open `index.html` in a web browser.

## Free publishing
A simple route is GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository named `halya-soaps`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open Settings → Pages.
5. Choose "Deploy from a branch", select the main branch and root folder, then save.
6. GitHub will give you a free website address.

## Before selling
Replace the demo product names/prices and placeholder product-image areas with your real products and photos. The checkout button is intentionally a demo; connect a payment/e-commerce provider before taking payments.

## Contact
Change `hello@halyasoaps.com` in index.html to your real business email.
